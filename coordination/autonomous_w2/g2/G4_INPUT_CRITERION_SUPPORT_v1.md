## Shared comparison target and criterion status

The v6 task rule itself is explicit: an action is eligible only if the same row has a replayed full-hold collision certificate, a replayed full-hold contact certificate, and a progress lower bound at least `7/20 m` for `p_x(T)-p_x(0)`. It is a formal task distinction relative to the declared zero/nominal comparators. An upper progress bound below threshold can establish formal task ineligibility on this domain; a progress interval overlapping the threshold is unresolved; safety `UNKNOWN` is not evidence of physical unsafety.

For any future matched evaluation, a common canonical input must bind, identically for both methods: the nine-state initial set, fixed label names and positive-width domains, fixed-label-across-hold semantics, plant/law and constants, exact held action, hold duration, exact obstacle and robot-footprint geometry (for v6, the one frozen inflated static circle), and input digest. The common outcome must evaluate the same full-hold collision and contact predicates and the same endpoint rule `progress_lower >= 0.35 m`. Each method can use its own valid enclosure, but differing proof granularity or UNKNOWN handling must be disclosed; no method should be credited for a different task rule.

The formal eligibility formula is not itself a frozen **cross-method primary hypothesis**. G4 found no outcome-independent matched input family, primary comparison metric, or independently justified binding resource effect for v6. Do not infer a comparison criterion from the observed v6 margins or the old selected R19/R20 pilot. The old ten-pair pilot (Auer 9/10, R3 6/10) remains descriptive development evidence, not a baseline result on the v6 task. A future study could prospectively choose certified eligible-action coverage under the shared rule, or a justified cost-at-matched-coverage question, but neither is frozen or authorized by this memo. Given the scoped negative contribution verdict and absent supported input adapters, the current branch is closed without a matched run.

As a concrete candidate for a future predeclared primary criterion, use paired task-group coverage, not a selected row's margin: for each prospectively defined group `g`, let `S_m(g)` be the set of the same three action voltages that method `m` certifies for full-hold collision, contact, and endpoint progress; let `C_m(g)=1` exactly when `S_m(g)` is nonempty. With `G` equal-weight groups, report `Delta=(sum_g C_G2(g)-sum_g C_Auer(g))/G`, the paired group discordances, and each `S_m(g)`. Keep action-level eligible-set differences secondary. Preserve proof `UNKNOWN`, resource limit, unsupported, audit failure and `NOT_RUN` as separate categories; they do not imply physical task failure. This candidate uses the W2 maximum of eight groups and three shared actions per group (24 rows per method), but it is **not frozen, not authorized by this memo, and not evidence of an existing advantage**. G4's no-run decision for v6 remains unchanged. A future cost claim would need a separate independently grounded resource target and full producer + replay + audit accounting at matched coverage.
