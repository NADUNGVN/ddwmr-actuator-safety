This contract covers the prescribed scalar law `clip(q,-1,1)` and one held voltage pair. It does not change the plant, certify physical contact, or promote G2/G4.

## Fixed labels, held action, and propagation

For the DDWMR query the input voltage `V=(-1,-1)` is held constant over the complete `T=1/50 s` hold. The twelve label coordinates use the complete declared benchmark image and satisfy `label_dot = 0`; their values may not be narrowed between steps. Every step record binds the same query ID, action, initial box, label image, horizon, method contract, arithmetic backend, source snapshot, and resource profile.

The first slab's start enclosure must contain the full initial box. For every later slab, the start enclosure must contain the previous separately certified endpoint enclosure. Equality is an acceptable sufficient case; mere overlap is not. Closed slab coverage must be exactly `[0,T]` with no gaps. The exported full-time hull must contain both closed endpoints. The checker evaluates collision and algebraic contact predicates over each closed slab and every obstacle. Endpoint-only checks cannot replace those full-time checks.

## Native record, independent replay, and composition contract

A future native step record must retain exact rational slab times; the approximate path and its derivative; the rough state/label domain; interval RHS and all 21-by-21 Jacobian entries; clip branch/range/derivative data; each residual iterate and its full-time derivative range; the recomputed inclusion premises; the total full-time hull; start and end enclosures; and work counters. The checker must independently parse those bytes, verify the proof-record SHA-256, recompute the branch/Jacobian and residual inclusion, and reject any mismatch before combining it with a common predicate result.

The typed composition record must bind, at minimum: query ID and canonical query-input digest; held voltage/action ID; initial box; all twelve labels; horizon and slab number; method-contract hash; backend-manifest hash; source-snapshot-manifest hash; resource-profile hash; native proof file hash; the exact exported `TubeSegment`; its full-time hull, separately certified endpoint, and radius mode/count; and the replayed common-check record hash. `CENTER_PLUS_RESIDUAL_ONCE` applies `x_app+R` exactly once. A native total hull uses expansion count zero. A bare digest string is provenance only until the native bytes replay.

The verifier rejects altered query/action/voltage, labels, horizon, proof bytes/hash, method/backend/source/profile binding, endpoint, radius mode/count, missing/reordered segment, or any modified segment. The adjacent endpoint containment is replayed. The common check remains `certificate_emitted=false` unless this complete proof-to-tube composition succeeds and is independently reviewed.

## Termination and result classification

`CERTIFIED` is reserved for a proof whose entire closed time tube, every residual inclusion, propagated endpoint, and required predicate replay successfully. A valid mathematical query with a failed inclusion, unresolved enclosure, or predeclared resource cap is `UNKNOWN` with the exact failed premise and counters. Malformed/out-of-domain inputs are `INVALID_INPUT`. Crashes, inconsistent interval intersections, source/hash mismatches, or disagreement between producer and checker are `IMPLEMENTATION_FAILURE`. Process exit code zero does not override a solver-reported incomplete condition. No branch split, time-step, precision, or work cap may be raised inside a frozen result series.

## Reconstruction deviations and current stop condition

This reconstruction changes the original software path in disclosed ways: it specializes the general Auer piecewise mechanism to the benchmark's continuous two-corner clip; targets the MASTER v2.1 nine physical states plus twelve constant label coordinates rather than the paper's friction/hysteresis example; proposes exact `Fraction` arithmetic and rational Taylor remainders in place of PROFIL/BIAS binary floating-point intervals; and requires JSON proof records plus an independent replay/composition layer. The pinned `ValEncIA-IVP_0.92_2e.cpp` is a smooth double-pendulum seed and does not contain the 2013 piecewise class. It has not been patched or used as a DDWMR solver.

**Stop condition:** only the RHS/Jacobian and clip preflight components exist. There is no residual/Picard IVP solver, no native inclusion record schema implementation, no independent inclusion checker, and no proof-to-common composition verifier. Accordingly, neither the analytic branch-crossing fixture nor the predeclared DDWMR Auer query may be reported as run or as proved under this contract. Solver work is blocked before the first IVP; continue only the independent documentation and archived R3 adapter case authorized by the assignment.
